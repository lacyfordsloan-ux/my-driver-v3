# my-driver-v3

Ride-hailing mini app for VK, built with Next.js and Supabase.

## Environment Variables Required

Set these in Vercel Project Settings → Environment Variables:

```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
VK_APP_SECRET=
JWT_SECRET=
YOOKASSA_SHOP_ID=
YOOKASSA_SECRET_KEY=
REDIS_URL=
```

## Tech Stack

- Next.js 16
- Supabase (PostgreSQL + Realtime)
- Socket.IO
- VK Bridge
